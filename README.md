
# Projeto: Arrays, DOM e Eventos

Este projeto foi feito para praticar os principais conceitos de JavaScript, trabalhando com arrays, manipulação de elementos HTML e eventos do usuário e enviar no Ava do Ceuma


- forEach: percorre os elementos de um array.
- map: cria um novo array com os elementos transformados.
- filter: filtra os elementos que atendem a uma condição.
- reduce: calcula um resultado a partir dos elementos, como a soma dos preços.
- DOM: permite alterar textos, criar elementos e adicionar classes à página.
- Eventos: permitem responder a cliques, teclas e envios de formulários.
